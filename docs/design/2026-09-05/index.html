Brooks visual system review / 5 September 2026

Five directions for a city that feels personal.

Each prototype is a self-contained, non-production preview of discovery, map, guide, creator, and trip flows. It uses fictional people, prices, guides, map locations, and no live APIs, payments, or tracking.

Recommended: 1. Atlas Studio. It gives map information and paid-guide decisions the clearest hierarchy, retains the pink Brooks signal as an accent rather than a background, and can be introduced into the existing design system with the least visual and accessibility risk.
